# 題庫補充與固定解析上線紀錄

截至 2026-10-11，正式 LINE 服務已部署 v27。現行 1,409 道選擇題均有預先生成的固定解析，學生作答後依選項呈現；自由追問仍由 AI 即時回應。使用者已完成 6 題手機操作，正式後台的解析文字、版本、計分及錯題紀錄核對全部通過。

本頁記錄 2026-10-08 至 2026-10-11 的累計工作及驗證範圍。這是公開的工作摘要，不包含教材全文、題庫資料集、原始作答紀錄或帳號資訊。

## 解析與參考來源

- 逐題整理原有解析的說明、選項辨析與參考來源，再以補充資料及固定解析提供給正式服務。
- 保留「正解／你選的／其他選項」格式；答對不重複顯示「你選的」，答錯時呈現所選選項的意思與辨析。
- 解說提供適用的漢字、讀音、意思與句中線索；參考來源以可開啟的連結呈現。
- 本批保留 76 題既有固定解析，新增 1,333 題目前題卡解析，另製作 37 個未顯示共同提示的舊題卡版本。
- 共 1,446 個可呈現的版本，涵蓋 5,784 種選答組合。新製內容共 1,370 個版本，均留存生成與第二輪模型複核紀錄。
- 另對 50 個版本作針對性編輯修訂，並處理 3 個來源補查項目。

預製內容仍屬 AI 生成；不同之處在於事先生成與保存，作答時直接呈現。第二輪模型複核、程式檢查及針對性編輯，不等於 1,409 題均經獨立人工或母語者認證，也不代表每題已證明具有唯一解。參考來源多沿用既有記錄，不能將本輪工作描述為重新查證全部來源。

## 程式行為

| 變更 | 正式服務行為 |
| --- | --- |
| 固定解析目錄 | 以題目、選項、答案、有效解析與提示內容綁定對應版本，避免題目改動後沿用不相符的解析 |
| 舊題卡相容 | 對尚未顯示提示的舊卡使用另行綁定的解析，不假設學生已看過新提示 |
| 內容不相符時 | 現行固定解析範圍內若無匹配內容，使用既定備援回覆，不偷偷改走即時模型生成 |
| 來源整合 | 合併現有來源及固定解析的補查來源，依網址去除重複 |
| 計分與複習 | 一般練習、錯題複習、每日挑戰、進度與重置流程配合既定練習政策 |
| 日誌 | 記錄實際回覆文字與固定解析版本；不把固定呈現標記為本次即時模型呼叫 |
| AI 助教 | 自由追問繼續使用即時 AI，並可取得該題的補充資訊 |

v27 本身透過部署檔案提供固定解析，沒有整批改寫 Supabase 原始 `explanation_rule`。先前的單題讀音修正與其他版本工作應按各自紀錄區分。
